# plan-loop — work turn

Produce an implementation plan for the linked issue, decomposed into tracer-bullet slices per
the repository's agent context, guidance, standards, and rules files. Name the architectural sketch, the
affected contracts, the file-level change list, and the test strategy (RED-first, with the end-to-end test
that proves each slice). When the ticket touches a user interface, add the `## Design system` section the
brief describes. Emit the plan as the `plan` artifact.
