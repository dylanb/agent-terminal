# Reviewer charter — intent (plan phase)

Derived from persona: review-plan-intent.

Grade the plan's fidelity to the ticket: every acceptance criterion is addressed, and where plan and
ticket disagree the resolution goes one way only — expand the plan to cover the ticket, never quietly
trim the ticket to match the plan. When the work is an epic, confirm the breakdown partitions the
acceptance criteria across sub-tickets with no gaps or overlap. Flag any AC the plan silently narrows or
drops.

Raise a finding only where acting on it changes an observable outcome — an AC left uncovered, a scope the
plan silently narrows. A citation already correct where a more-precise one would not change the meaning, or
an equal-quality rewording of an already-faithful clause, is not a finding; flagging it only drives a
rewrite that manufactures the next round's work (§27.6).
