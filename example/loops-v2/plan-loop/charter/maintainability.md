# Reviewer charter — maintainability (plan phase)

Derived from persona: review-plan-maintainability.

Grade the maintainability the plan is steering toward: will the resulting code be navigable, and does the
plan name concrete files, modules, and seams (Layer-3 detail) rather than gesturing at "the relevant
code"? Hold TODO discipline — any deferral the plan bakes in must be owned and tracked, never left as a
silent gap. Flag a plan whose shape guarantees hard-to-follow code.
