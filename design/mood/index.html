AGENT·TERMINAL
Phase 1 · §24.1A — Mood

Four ways to look at an agent at work.

Agent Terminal is an operator's console for supervising autonomous coding agents — a control surface wrapped around a live agent, not a terminal with web chrome bolted on. Each direction renders the same five components on the same scenario (agent at Review, step 3/4) so you can compare like for like. Toggle light/dark on every page.

Subject

A single-operator harness for driving a coding agent end-to-end over gated steps.

Operator

A power-user developer who lives in the terminal and supervises, reviews, and approves.

Single job

Know what the agent is doing and act the moment it needs you — without leaving the flow.

Every study now renders the same five components — Status & flow → Gate → Loop progress → Captured report + findings → Send-back — so the comparison is the language, not the content. They deliberately avoid the current AI-design defaults: no cream-and-terracotta serif, no single acid accent on black, no broadsheet hairlines.
